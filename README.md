# Mi Sitio Web

Estructura base para promocionar servicios de desarrollo de software.

## Cómo usarlo en Visual Studio (VS Code)

1. Descomprime esta carpeta y ábrela en VS Code (`File > Open Folder`).
2. Instala la extensión **Live Server**.
3. Haz clic derecho en `index.html` y elige **Open with Live Server**.
4. Edita textos, colores (`css/styles.css`) y agrega tu logo en `assets/images/`.

## Estructura

```
mi-sitio-web/
├── assets/
│   ├── images/     # Logotipos, iconos y fotografías del sitio
│   └── icons/      # Favicon y vectores SVG
├── css/
│   ├── styles.css      # Estilos globales de la página
│   └── responsive.css  # Reglas para teléfonos y tablets
├── js/
│   ├── main.js          # Lógica principal e interacción
│   └── components/      # Scripts específicos (menú, formularios, etc.)
├── index.html       # Página principal (Home)
├── contacto.html     # Formulario de contacto
└── servicios.html    # Detalle de servicios
```

## Próximos pasos sugeridos

- Reemplazar los textos de ejemplo por tu contenido real.
- Agregar tu logo en `assets/images/logo.png`.
- Conectar el formulario de contacto a un servicio real (Formspree, EmailJS, o tu propio backend).
- Publicar el sitio con GitHub Pages, Netlify o Vercel.
